# LED 光源选购与灯光设计指南

单文件 HTML 知识库页面：**筒灯（Downlight）/ 射灯（Spotlight、轨道灯、磁吸灯）/ 灯带（Strip、COB、霓虹）**。

主要依据 **GB/T 50034-2024《建筑照明设计标准》** 与 **GB 55016-2021《建筑环境通用规范》**，产品数据取自厂商公开规格与 DIALux 光度库，含 116 条来源链接与 16 张内联示意图。

## 在线阅读（GitHub Pages）

<https://bobhhu97.github.io/led-lighting-guide/>

## 本地查看

```bash
git clone https://github.com/bobhhu97/led-lighting-guide.git
cd led-lighting-guide
open index.html          # macOS
# Linux: xdg-open index.html
```

无需构建、无外部依赖、无网络请求，双击即可打开；浏览器「打印」可直接输出排版好的 A4 PDF。
